# 🧪 Web Lab - Modern Frontend Mini-Projects

Welcome to Web Lab! Ye repository alag-alag modern aur trendy frontend UI designs ka collection hai. Isko bina kisi heavy framework ke, pure HTML, CSS aur JavaScript se banaya hai taki core concepts aur UI/UX skills strong ho sakein.

## 🚀 Live Preview

## 🛠️ Tech Stack
* **HTML5:** Clean aur semantic structure.
* **CSS3:** Modern UI trends, Flexbox, CSS Grid, aur 3D Transforms.
* **Vanilla JavaScript:** ES6+, Async/Await, Fetch API, aur LocalStorage.
